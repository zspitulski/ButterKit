# Security

If you find a security problem in ButterKit, the `butterkit-mcp` bridge or butterkit.app, please report it privately so it can be fixed before anyone else learns about it.

## How to report

- **On GitHub:** open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainer can see the report.
- **By email, if you can't use GitHub:** write to [help@butterkit.app](mailto:help@butterkit.app) with "Security" in the subject.

Please include what you found, the ButterKit version (**ButterKit > About ButterKit**), your macOS version, and the steps to reproduce it. Please don't open a public issue for security problems.

## What happens next

ButterKit is made by one person, and security reports go to the front of the line. You'll get a reply as soon as possible, and you'll hear when a fix ships. With your permission, you'll be credited in the release notes.

## Supported versions

Fixes go into the latest release. Keep ButterKit updated through the Mac App Store or the app's built-in updater.
