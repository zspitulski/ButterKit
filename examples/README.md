# Examples

Ready-to-copy setups for getting screenshots into ButterKit and driving it from your tools.

| Example | What it shows |
| --- | --- |
| [fastlane](fastlane/README.md) | A lane that captures screenshots and lays them out for a linked folder |
| [Linked folders](linked-folders/README.md) | Every folder layout ButterKit understands, and how files map to devices and languages |
| [Agent prompts](agent-prompts/README.md) | Prompts for Claude Code, Cursor or Codex in ChatGPT once ButterKit's MCP server is connected |

Have a setup worth sharing? Open an issue with what you built and it may land here.
